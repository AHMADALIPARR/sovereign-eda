Evidence lives in reports/test-results/ (gate logs, produced by
scripts/release-gate.sh) and in reports/release-readiness/ (the
readiness report, regenerated by the gate on every run). Formal
evidence is in verification/formal/formal-evidence.md. Static
analysis is in verification/static-analysis/static-analysis.md.
Property tests are in verification/property-tests/property-tests.md.

A check that did not run is recorded as BLOCKED or NOT RUN in the
gate log. It is never recorded as passed.
