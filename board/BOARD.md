NATS subjects \rightarrow Net names / Named pipes (mkfifo): A node/net (in, n1, 0) is the shared bus; fan-out is just multiple lines referencing the same net token.
Erlang processes & functors \rightarrow awk filters: Stateless text transformations map schematic records into SPICE decks, structural netlists, or discrete-time analog sample streams over stdin/stdout.
1. Plain-Text Circuit Board Format (board.txt)
Keep one component or directive per line, whitespace-delimited, with # or * comments:
# RC Low-Pass Filter + Diode Clipper
V1   in   0     SIN(0 5 1k)
R1   in   out   1k
C1   out  0     100n
D1   out  0     DMOD

.model DMOD D(IS=1e-14 N=1)
.tran 10u 5m
2. Zero-Dependency awk EDA Compiler (eda.awk)
This single POSIX awk script compiles board.txt into a SPICE deck (mode=spice), a pin-to-net Netlist (mode=netlist), or a connectivity check (flagging floating single-pin nets to stderr):
#!/usr/bin/awk -f
# eda.awk — Zero-dependency Virtual EDA (POSIX awk)
# Modes: -v mode=spice (default) | -v mode=netlist

BEGIN {
    if (mode == "") mode = "spice"
    comp_count = 0
}

# Strip comments and blank lines
{
    sub(/#.*/, "")
    gsub(/^[ \t]+|[ \t]+$/, "")
    if ($0 == "" || $0 ~ /^\*/) next
}

# Pass SPICE dot-directives through in spice mode
/^\./ {
    directives[++dir_count] = $0
    next
}

# Parse component lines: <REFDES> <NODE1> <NODE2> [NODE3...] <VALUE/MODEL>
{
    ref = $1
    val = $NF
    comp_count++
    refs[comp_count] = ref
    vals[comp_count] = val

    # Collect intermediate pins/nets (fields 2 .. NF-1)
    nets_str = ""
    for (i = 2; i < NF; i++) {
        n = tolower($i)
        if (n == "gnd") n = "0"
        nets_str = (nets_str == "" ? n : nets_str " " n)
        net_deg[n]++
        net_pins[n] = (net_pins[n] == "" ? ref ".p" (i-1) : net_pins[n] " " ref ".p" (i-1))
    }
    comp_nets[comp_count] = nets_str
}

END {
    # ERC: Warn on floating nets (degree == 1, excluding ground "0")
    for (n in net_deg) {
        if (n != "0" && net_deg[n] < 2) {
            printf "ERC WARNING: floating net '%s' (%s)\n", n, net_pins[n] > "/dev/stderr"
        }
    }

    if (mode == "spice") {
        print "* Generated by eda.awk"
        for (i = 1; i <= comp_count; i++) {
            printf "%-6s %-18s %s\n", refs[i], comp_nets[i], vals[i]
        }
        for (d = 1; d <= dir_count; d++) {
            print directives[d]
        }
        print ".end"
    } else if (mode == "netlist") {
        print "# NETLIST (NET -> PINS)"
        for (n in net_pins) {
            printf "%-10s : %s\n", n, net_pins[n]
        }
    }
}
3. UNIX Piping into SPICE & Analog IPC
Compile and pipe directly into SPICE (ngspice / xyce) or inspect the netlist:
# Pipe directly into ngspice batch mode
awk -v mode=spice -f eda.awk board.txt | ngspice -b -

# Extract structural netlist + run ERC
awk -v mode=netlist -f eda.awk board.txt | sort
UNIX-Style Analog IPC (Streaming Signal Pipes without SPICE): If you want to run live analog blocks as decoupled UNIX processes (the zero-dependency replacement for NATS pub/sub + Erlang actors), treat each line on stdin/stdout as a (time, voltage) sample and wire blocks with | or mkfifo:
# Signal generator -> RC low-pass filter (backward Euler) -> CSV/plotter
awk 'BEGIN { for (t=0; t<0.005; t+=1e-5) printf "%.6f %.6f\n", t, 5*sin(2*3.14159*1000*t) }' \
| awk -v R=1000 -v C=1e-7 -v dt=1e-5 '
    BEGIN { vout = 0; alpha = dt / (R*C + dt) }
    { vout = vout + alpha * ($2 - vout); printf "%.6f %.6f %.6f\n", $1, $2, vout }
  '
For feedback loops (oscillators, op-amp summing nodes), create a named pipe (mkfifo fb.pipe) to route stdout of the downstream stage back into the stdin of the summing awk stage.

Here is the full zero-dependency POSIX awk extension (eda.awk) supporting Verilog-A (.va behavioral blocks and full-board Verilog-A synthesis), SPICE, structural Netlist + BOM, and KiCad S-expression netlists—all over standard UNIX pipes.
1. Extended Board Format (board.txt)
Supports standard primitives, subcircuits (.subckt/.ends), and inline Verilog-A behavioral blocks (.va/.endva):
# Hybrid Analog Board: RC Filter + Behavioral Nonlinear Memristive Load
V1   in   0     5.0
R1   in   out   1k
C1   out  0     100n
X1   out  0     soft_clipper  R0=2k  Vth=1.2

# Inline Verilog-A behavioral module
.va soft_clipper p n R0=1k Vth=0.7
    I(p, n) <+ (V(p, n) / R0) + 1e-6 * sinh(V(p, n) / Vth);
.endva

.tran 10u 5m
2. Full POSIX awk EDA Compiler (eda.awk)
Supports four output modes via -v mode=...:
spice (default): Emits a SPICE deck (.cir) with .hdl Verilog-A links, gnd \rightarrow 0 normalization, and ERC checks.
veriloga / va: Emits a complete Verilog-A file (.va) containing all .va behavioral modules plus a synthesized board_top module translating R, C, L, V, I, and X instances into KCL branch contributions (I(...) <+ ..., ddt(...)) with SI-to-scientific unit conversion.
netlist: Emits a full component table, net-to-pin connectivity list with fanout degree, and aggregated BOM.
kicad: Emits a KiCad S-expression netlist (.net).
#!/usr/bin/awk -f
# eda.awk — Zero-dependency POSIX Virtual EDA
# Modes: -v mode=spice | veriloga | netlist | kicad

function si_to_real(s,    low) {
    low = tolower(s)
    if (low ~ /^[0-9.eE+-]+meg$/) { sub(/meg$/, "e6", low);  return low }
    if (low ~ /^[0-9.eE+-]+t$/)   { sub(/t$/,   "e12", low); return low }
    if (low ~ /^[0-9.eE+-]+g$/)   { sub(/g$/,   "e9", low);  return low }
    if (low ~ /^[0-9.eE+-]+k$/)   { sub(/k$/,   "e3", low);  return low }
    if (low ~ /^[0-9.eE+-]+m$/)   { sub(/m$/,   "e-3", low); return low }
    if (low ~ /^[0-9.eE+-]+u$/)   { sub(/u$/,   "e-6", low); return low }
    if (low ~ /^[0-9.eE+-]+n$/)   { sub(/n$/,   "e-9", low); return low }
    if (low ~ /^[0-9.eE+-]+p$/)   { sub(/p$/,   "e-12", low); return low }
    if (low ~ /^[0-9.eE+-]+f$/)   { sub(/f$/,   "e-15", low); return low }
    return s
}

function norm_net(n,    low) {
    low = tolower(n)
    return (low == "gnd" || low == "0") ? "0" : low
}

function add_net(n, ref, pin_idx) {
    if (!(n in net_seen)) {
        net_seen[n] = 1
        net_list[++net_count] = n
    }
    net_deg[n]++
    net_pins[n] = (net_pins[n] == "" ? ref "." pin_idx : net_pins[n] " " ref "." pin_idx)
}

BEGIN {
    if (mode == "") mode = "spice"
    if (mode == "va") mode = "veriloga"
}

# Capture raw lines inside .va ... .endva blocks
in_va {
    if (tolower($1) == ".endva") {
        in_va = 0
        next
    }
    va_body[va_cur, ++va_lines[va_cur]] = $0
    next
}

# Strip comments and whitespace
{
    sub(/#.*/, "")
    gsub(/^[ \t]+|[ \t]+$/, "")
    if ($0 == "" || $0 ~ /^\*/) next
}

# Capture .subckt ... .ends verbatim for SPICE
tolower($1) == ".subckt" {
    in_subckt = 1
    subckt_lines[++subckt_count] = $0
    next
}
in_subckt {
    subckt_lines[++subckt_count] = $0
    if (tolower($1) == ".ends") in_subckt = 0
    next
}

# Parse .va <name> <ports...> [param=val...]
tolower($1) == ".va" {
    in_va = 1
    va_cur = ++va_count
    va_name[va_cur] = $2
    for (i = 3; i <= NF; i++) {
        if ($i ~ /=/) {
            split($i, kv, "=")
            va_pcount[va_cur]++
            va_pname[va_cur, va_pcount[va_cur]] = kv[1]
            va_pval[va_cur, va_pcount[va_cur]]  = si_to_real(kv[2])
        } else {
            va_portcount[va_cur]++
            va_port[va_cur, va_portcount[va_cur]] = norm_net($i)
        }
    }
    next
}

# Pass other SPICE dot-directives
/^\./ {
    directives[++dir_count] = $0
    next
}

# Parse component: <REF> <NET1> <NET2> [NET3...] <VAL_OR_MODEL> [PARAM=VAL...]
{
    ref = $1
    if (seen_ref[ref]++) {
        printf "ERC WARNING: duplicate reference '%s'\n", ref > "/dev/stderr"
    }

    c_idx = ++comp_count
    c_ref[c_idx]  = ref
    c_type[c_idx] = toupper(substr(ref, 1, 1))
    c_raw[c_idx]  = $0

    # Separate trailing key=val parameters from positional tokens
    last_pos = NF
    p_str = ""
    while (last_pos > 2 && $last_pos ~ /=/) {
        p_str = ($last_pos) (p_str == "" ? "" : " " p_str)
        last_pos--
    }
    c_params[c_idx] = p_str
    c_val[c_idx]    = $last_pos

    nets_str = ""
    c_nports[c_idx] = 0
    for (i = 2; i < last_pos; i++) {
        n = norm_net($i)
        c_nports[c_idx]++
        c_port[c_idx, c_nports[c_idx]] = n
        nets_str = (nets_str == "" ? n : nets_str " " n)
        add_net(n, ref, i - 1)
    }
    c_nets[c_idx] = nets_str

    bom_key = c_type[c_idx] "|" c_val[c_idx]
    if (!(bom_key in bom_seen)) {
        bom_seen[bom_key] = 1
        bom_keys[++bom_count] = bom_key
    }
    bom_qty[bom_key]++
    bom_refs[bom_key] = (bom_refs[bom_key] == "" ? ref : bom_refs[bom_key] ", " ref)
}

END {
    # ERC Checks
    if (!("0" in net_seen)) {
        print "ERC WARNING: no ground reference ('0' or 'gnd') found" > "/dev/stderr"
    }
    for (i = 1; i <= net_count; i++) {
        n = net_list[i]
        if (n != "0" && net_deg[n] < 2) {
            printf "ERC WARNING: floating net '%s' (%s)\n", n, net_pins[n] > "/dev/stderr"
        }
    }

    if (mode == "spice") {
        print "* Virtual EDA SPICE Netlist (eda.awk)"
        if (va_count > 0) {
            print "* Note: compile Verilog-A modules with OpenVAF/ADMS or .hdl"
            for (v = 1; v <= va_count; v++) {
                printf "* .hdl \"%s.va\"\n", va_name[v]
            }
        }
        for (s = 1; s <= subckt_count; s++) print subckt_lines[s]
        for (i = 1; i <= comp_count; i++) {
            printf "%-6s %-18s %s%s\n", c_ref[i], c_nets[i], c_val[i], (c_params[i] != "" ? " " c_params[i] : "")
        }
        for (d = 1; d <= dir_count; d++) print directives[d]
        print ".end"
    }
    else if (mode == "veriloga") {
        print "`include \"constants.vams\""
        print "`include \"disciplines.vams\""
        print ""

        # 1. Emit user-defined .va behavioral modules
        for (v = 1; v <= va_count; v++) {
            printf "module %s(", va_name[v]
            for (p = 1; p <= va_portcount[v]; p++) {
                printf "%s%s", va_port[v, p], (p < va_portcount[v] ? ", " : "")
            }
            print ");"
            for (p = 1; p <= va_portcount[v]; p++) {
                printf "    inout %s;\n    electrical %s;\n", va_port[v, p], va_port[v, p]
            }
            for (k = 1; k <= va_pcount[v]; k++) {
                printf "    parameter real %s = %s;\n", va_pname[v, k], va_pval[v, k]
            }
            print "    analog begin"
            for (l = 1; l <= va_lines[v]; l++) {
                print "        " va_body[v, l]
            }
            print "    end"
            print "endmodule\n"
        }

        # 2. Synthesize top-level board module
        print "module board_top();"
        print "    ground gnd;"
        for (i = 1; i <= net_count; i++) {
            n = net_list[i]
            va_n = (n == "0" ? "gnd" : "n_" n)
            if (n != "0") printf "    electrical %s;\n", va_n
        }

        # Instantiate X/Y subblocks outside analog block
        for (i = 1; i <= comp_count; i++) {
            if (c_type[i] == "X") {
                p_list = ""
                for (p = 1; p <= c_nports[i]; p++) {
                    pn = c_port[i, p]
                    vn = (pn == "0" ? "gnd" : "n_" pn)
                    p_list = (p_list == "" ? vn : p_list ", " vn)
                }
                param_ov = ""
                if (c_params[i] != "") {
                    np = split(c_params[i], pa, " ")
                    for (j = 1; j <= np; j++) {
                        split(pa[j], kv, "=")
                        param_ov = param_ov (param_ov == "" ? "" : ", ") "." kv[1] "(" si_to_real(kv[2]) ")"
                    }
                    param_ov = " #(" param_ov ")"
                }
                printf "    %s%s %s(%s);\n", c_val[i], param_ov, c_ref[i], p_list
            }
        }

        print "    analog begin"
        for (i = 1; i <= comp_count; i++) {
            t = c_type[i]
            if (t == "X") continue
            n1 = (c_port[i, 1] == "0" ? "gnd" : "n_" c_port[i, 1])
            n2 = (c_port[i, 2] == "0" ? "gnd" : "n_" c_port[i, 2])
            val = si_to_real(c_val[i])

            if (t == "R") {
                printf "        I(%s, %s) <+ V(%s, %s) / (%s); // %s\n", n1, n2, n1, n2, val, c_ref[i]
            } else if (t == "C") {
                printf "        I(%s, %s) <+ (%s) * ddt(V(%s, %s)); // %s\n", n1, n2, val, n1, n2, c_ref[i]
            } else if (t == "L") {
                printf "        V(%s, %s) <+ (%s) * ddt(I(%s, %s)); // %s\n", n1, n2, val, n1, n2, c_ref[i]
            } else if (t == "V") {
                printf "        V(%s, %s) <+ %s; // %s\n", n1, n2, val, c_ref[i]
            } else if (t == "I") {
                printf "        I(%s, %s) <+ %s; // %s\n", n1, n2, val, c_ref[i]
            } else {
                printf "        // %s (%s): instantiate via .subckt or .va\n", c_ref[i], c_val[i]
            }
        }
        print "    end"
        print "endmodule"
    }
    else if (mode == "netlist") {
        print "=== COMPONENTS ==="
        for (i = 1; i <= comp_count; i++) {
            printf "%-6s %-4s %-12s %s\n", c_ref[i], c_type[i], c_val[i], c_nets[i]
        }
        print "\n=== NETS (DEGREE : PINS) ==="
        for (i = 1; i <= net_count; i++) {
            n = net_list[i]
            printf "%-10s [%d] : %s\n", n, net_deg[n], net_pins[n]
        }
        print "\n=== BOM ==="
        for (b = 1; b <= bom_count; b++) {
            k = bom_keys[b]
            split(k, kv, "|")
            printf "%-4s %-12s qty=%-3d (%s)\n", kv[1], kv[2], bom_qty[k], bom_refs[k]
        }
    }
    else if (mode == "kicad") {
        print "(export (version \"E\")"
        print "  (components"
        for (i = 1; i <= comp_count; i++) {
            printf "    (comp (ref \"%s\") (value \"%s\"))\n", c_ref[i], c_val[i]
        }
        print "  )"
        print "  (nets"
        for (i = 1; i <= net_count; i++) {
            n = net_list[i]
            printf "    (net (code \"%d\") (name \"%s\")\n", i, n
            np = split(net_pins[n], pa, " ")
            for (j = 1; j <= np; j++) {
                split(pa[j], rp, ".")
                printf "      (node (ref \"%s\") (pin \"%s\"))\n", rp[1], rp[2]
            }
            print "    )"
        }
        print "  )"
        print ")"
    }
}

Modified Nodal Analysis (MNA) solver in pure POSIX awk (mna.awk). It reads board.txt directly from stdin (or a file), solves DC operating points and Backward-Euler transient simulations—including nonlinear diodes via Newton-Raphson—and streams time-series node voltages to stdout.

Pure-awk MNA Solver (mna.awk)
Supports R, C, L, V (DC and SIN(vo va freq)), I, D (nonlinear Shockley diode), and .tran <tstep> <tstop>:
#!/usr/bin/awk -f
# mna.awk — Zero-dependency POSIX awk MNA Circuit Solver (DC + Transient)
# Usage: awk -f mna.awk board.txt

function si(s,    low) {
    low = tolower(s)
    if (low ~ /^[0-9.eE+-]+meg$/) { sub(/meg$/, "e6", low);  return low + 0 }
    if (low ~ /^[0-9.eE+-]+t$/)   { sub(/t$/,   "e12", low); return low + 0 }
    if (low ~ /^[0-9.eE+-]+g$/)   { sub(/g$/,   "e9", low);  return low + 0 }
    if (low ~ /^[0-9.eE+-]+k$/)   { sub(/k$/,   "e3", low);  return low + 0 }
    if (low ~ /^[0-9.eE+-]+m$/)   { sub(/m$/,   "e-3", low); return low + 0 }
    if (low ~ /^[0-9.eE+-]+u$/)   { sub(/u$/,   "e-6", low); return low + 0 }
    if (low ~ /^[0-9.eE+-]+n$/)   { sub(/n$/,   "e-9", low); return low + 0 }
    if (low ~ /^[0-9.eE+-]+p$/)   { sub(/p$/,   "e-12", low);return low + 0 }
    if (low ~ /^[0-9.eE+-]+f$/)   { sub(/f$/,   "e-15", low);return low + 0 }
    return s + 0
}

function get_node(name,    low) {
    low = tolower(name)
    if (low == "0" || low == "gnd") return 0
    if (!(low in node_id)) {
        node_id[low] = ++num_nodes
        node_name[num_nodes] = low
    }
    return node_id[low]
}

function eval_src(idx, t,    vo, va, f) {
    if (c_src_type[idx] == "SIN") {
        vo = c_vo[idx]; va = c_va[idx]; f = c_freq[idx]
        return vo + va * sin(2 * 3.141592653589793 * f * t)
    }
    return c_val[idx]
}

function stamp_res(n1, n2, g) {
    if (n1 > 0) A[n1, n1] += g
    if (n2 > 0) A[n2, n2] += g
    if (n1 > 0 && n2 > 0) { A[n1, n2] -= g; A[n2, n1] -= g }
}

function solve_linear(N,    i, j, k, piv, maxv, tmp, factor, sum) {
    for (k = 1; k <= N; k++) {
        piv = k; maxv = (A[k, k] < 0 ? -A[k, k] : A[k, k])
        for (i = k + 1; i <= N; i++) {
            tmp = (A[i, k] < 0 ? -A[i, k] : A[i, k])
            if (tmp > maxv) { maxv = tmp; piv = i }
        }
        if (piv != k) {
            for (j = k; j <= N; j++) {
                tmp = A[k, j]; A[k, j] = A[piv, j]; A[piv, j] = tmp
            }
            tmp = b[k]; b[k] = b[piv]; b[piv] = tmp
        }
        if (A[k, k] == 0) {
            printf "MNA ERROR: singular matrix at row %d\n", k > "/dev/stderr"
            exit 1
        }
        for (i = k + 1; i <= N; i++) {
            factor = A[i, k] / A[k, k]
            if (factor != 0) {
                for (j = k; j <= N; j++) A[i, j] -= factor * A[k, j]
                b[i] -= factor * b[k]
            }
        }
    }
    for (i = N; i >= 1; i--) {
        sum = b[i]
        for (j = i + 1; j <= N; j++) sum -= A[i, j] * x[j]
        x[i] = sum / A[i, i]
    }
}

function stamp_and_solve(t, dt,    N, nr, max_nr, i, j, ty, n1, n2, br, val, g, vp, ieq, vd, e, gd, id, diff, maxd) {
    N = num_nodes + num_branches
    max_nr = (has_diode ? 20 : 1)

    for (i = 1; i <= N; i++) x_nr[i] = x_prev[i]

    for (nr = 1; nr <= max_nr; nr++) {
        for (i = 1; i <= N; i++) {
            b[i] = 0
            for (j = 1; j <= N; j++) A[i, j] = 0
        }

        for (i = 1; i <= comp_count; i++) {
            ty = c_type[i]; n1 = c_n1[i]; n2 = c_n2[i]

            if (ty == "R") {
                stamp_res(n1, n2, 1.0 / c_val[i])
            } else if (ty == "C" && dt > 0) {
                g = c_val[i] / dt
                vp = (n1 > 0 ? x_prev[n1] : 0) - (n2 > 0 ? x_prev[n2] : 0)
                ieq = g * vp
                stamp_res(n1, n2, g)
                if (n1 > 0) b[n1] += ieq
                if (n2 > 0) b[n2] -= ieq
            } else if (ty == "L") {
                br = num_nodes + c_br[i]
                if (n1 > 0) { A[n1, br] += 1; A[br, n1] += 1 }
                if (n2 > 0) { A[n2, br] -= 1; A[br, n2] -= 1 }
                if (dt > 0) {
                    val = c_val[i] / dt
                    A[br, br] -= val
                    b[br] -= val * x_prev[br]
                }
            } else if (ty == "V") {
                br = num_nodes + c_br[i]
                if (n1 > 0) { A[n1, br] += 1; A[br, n1] += 1 }
                if (n2 > 0) { A[n2, br] -= 1; A[br, n2] -= 1 }
                b[br] += eval_src(i, t)
            } else if (ty == "I") {
                val = eval_src(i, t)
                if (n1 > 0) b[n1] -= val
                if (n2 > 0) b[n2] += val
            } else if (ty == "D") {
                vd = (n1 > 0 ? x_nr[n1] : 0) - (n2 > 0 ? x_nr[n2] : 0)
                # Shockley diode (Is=1e-14, Vt=0.02585), linearized above 0.8V
                if (vd > 0.8) {
                    e = exp(0.8 / 0.02585)
                    gd = (1e-14 / 0.02585) * e
                    id = 1e-14 * (e - 1.0) + gd * (vd - 0.8)
                } else if (vd < -5.0) {
                    gd = 1e-12
                    id = -1e-14 + gd * vd
                } else {
                    e = exp(vd / 0.02585)
                    gd = (1e-14 / 0.02585) * e + 1e-12
                    id = 1e-14 * (e - 1.0)
                }
                ieq = id - gd * vd
                stamp_res(n1, n2, gd)
                if (n1 > 0) b[n1] -= ieq
                if (n2 > 0) b[n2] += ieq
            }
        }

        solve_linear(N)

        maxd = 0
        for (i = 1; i <= N; i++) {
            diff = x[i] - x_nr[i]
            if (diff < 0) diff = -diff
            if (diff > maxd) maxd = diff
            x_nr[i] = x[i]
        }
        if (maxd < 1e-9) break
    }
    for (i = 1; i <= N; i++) x_prev[i] = x[i]
}

    tstep = 0; tstop = 0; has_diode = 0
}

module State
  use int.Int

  type mode = Idle | Calibrate | Run | Fault

  type t = {
    mode : mode;
    phase_err : int;
    cal_word : int;
    locked : bool;
  }

  predicate inv (s: t) =
    0 <= s.cal_word <= 255 /\
    -128 <= s.phase_err <= 127 /\
    (s.mode = Run -> s.locked = true) /\
    (s.mode = Fault -> s.locked = false)

  function init : t =
    { mode = Idle; phase_err = 0; cal_word = 128; locked = false }

  lemma init_inv : inv init

  function step (s: t) (start: bool) (err: int) : t =
    if s.mode = Fault then s
    else if not (-128 <= err <= 127) then
      { mode = Fault; phase_err = 0; cal_word = s.cal_word; locked = false }
    else match s.mode with
      | Idle ->
          if start then { mode = Calibrate; phase_err = err; cal_word = s.cal_word; locked = false }
          else s
      | Calibrate ->
          if -2 <= err <= 2 then { mode = Run; phase_err = err; cal_word = s.cal_word; locked = true }
          else
            let next_cal = if err > 0 then (if s.cal_word > 0 then s.cal_word - 1 else 0)
                           else (if s.cal_word < 255 then s.cal_word + 1 else 255) in
            { mode = Calibrate; phase_err = err; cal_word = next_cal; locked = false }
      | Run ->
          if -4 <= err <= 4 then { mode = Run; phase_err = err; cal_word = s.cal_word; locked = true }
          else { mode = Calibrate; phase_err = err; cal_word = s.cal_word; locked = false }
      | Fault -> s
    end

  lemma step_preserves_inv :
    forall s: t, start: bool, err: int.
      inv s -> inv (step s start err)
end

module SRAM
  use int.Int
  use map.Map

  constant depth : int = 256

  type mem = map int int

  type t = {
    data : mem;
    we   : bool;
    addr : int;
    din  : int;
    dout : int;
  }

  predicate valid_addr (a: int) = 0 <= a < depth

  predicate inv (m: t) =
    valid_addr m.addr /\
    0 <= m.din < 4294967296 /\
    0 <= m.dout < 4294967296

  function write_mem (m: mem) (a: int) (v: int) : mem =
    Map.set m a v

  function read_mem (m: mem) (a: int) : int =
    Map.get m a

  function cycle (m: t) (we: bool) (a: int) (v: int) : t
    requires { valid_addr a /\ 0 <= v < 4294967296 }
  =
    let next_data = if we then write_mem m.data a v else m.data in
    let next_dout = read_mem next_data a in
    { data = next_data; we = we; addr = a; din = v; dout = next_dout }

  lemma write_then_read :
    forall m: t, a: int, v: int.
      valid_addr a -> 0 <= v < 4294967296 ->
      (cycle m true a v).dout = v
end

module State where

type Mode = [2]
IDLE      = 0 : Mode
CALIBRATE = 1 : Mode
RUN       = 2 : Mode
FAULT     = 3 : Mode

type CtrlState = {
    mode      : Mode,
    phase_err : [8],
    cal_word  : [8],
    locked    : Bit
}

init_state : CtrlState
init_state = {
    mode      = IDLE,
    phase_err = 0,
    cal_word  = 128,
    locked    = False
}

abs8 : [8] -> [8]
abs8 x = if (x ! 0) then -x else x

step_state : CtrlState -> Bit -> [8] -> CtrlState
step_state s start err =
    if s.mode == FAULT then s
    else if s.mode == IDLE then
        if start then { mode = CALIBRATE, phase_err = err, cal_word = s.cal_word, locked = False }
        else s
    else if s.mode == CALIBRATE then
        if abs8 err <= 2 then
            { mode = RUN, phase_err = err, cal_word = s.cal_word, locked = True }
        else
            { mode = CALIBRATE, phase_err = err, cal_word = next_cal, locked = False }
            where next_cal =
                if ~(err ! 0) && err != 0 then (if s.cal_word > 0 then s.cal_word - 1 else 0)
                else (if s.cal_word < 255 then s.cal_word + 1 else 255)
    else // RUN
        if abs8 err <= 4 then
            { mode = RUN, phase_err = err, cal_word = s.cal_word, locked = True }
        else
            { mode = CALIBRATE, phase_err = err, cal_word = s.cal_word, locked = False }

property run_implies_locked s start err =
    (s'.mode == RUN) ==> s'.locked
    where s' = step_state s start err

entity p4_controller is
    port (
        clk        : in  std_logic;
        rst_n      : in  std_logic;
        start      : in  std_logic;
        phase_err  : in  signed(7 downto 0);
        cal_word   : out unsigned(7 downto 0);
        mode_out   : out std_logic_vector(1 downto 0);
        locked     : out std_logic;
        sram_we_en : out std_logic
    );
end entity p4_controller;

architecture rtl of p4_controller is
    type mode_t is (MODE_IDLE, MODE_CALIBRATE, MODE_RUN, MODE_FAULT);
    signal mode_reg : mode_t := MODE_IDLE;
    signal cal_reg  : unsigned(7 downto 0) := to_unsigned(128, 8);
    signal lock_reg : std_logic := '0';
begin
    process(clk, rst_n)
        variable err_abs : unsigned(7 downto 0);
    begin
        if rst_n = '0' then
            mode_reg <= MODE_IDLE;
            cal_reg  <= to_unsigned(128, 8);
            lock_reg <= '0';
        elsif rising_edge(clk) then
            if phase_err < 0 then
                err_abs := unsigned(-phase_err);
            else
                err_abs := unsigned(phase_err);
            end if;

            case mode_reg is
                when MODE_IDLE =>
                    lock_reg <= '0';
                    if start = '1' then
                        mode_reg <= MODE_CALIBRATE;
                    end if;

                when MODE_CALIBRATE =>
                    if err_abs <= 2 then
                        mode_reg <= MODE_RUN;
                        lock_reg <= '1';
                    else
                        lock_reg <= '0';
                        if phase_err > 0 then
                            if cal_reg > 0 then
                                cal_reg <= cal_reg - 1;
                            end if;
                        else
                            if cal_reg < 255 then
                                cal_reg <= cal_reg + 1;
                            end if;
                        end if;
                    end if;

                when MODE_RUN =>
                    if err_abs <= 4 then
                        lock_reg <= '1';
                    else
                        mode_reg <= MODE_CALIBRATE;
                        lock_reg <= '0';
                    end if;

                when MODE_FAULT =>
                    lock_reg <= '0';
            end case;
        end if;
    end process;

    cal_word   <= cal_reg;
    locked     <= lock_reg;
    sram_we_en <= '1' when (mode_reg = MODE_RUN and lock_reg = '1') else '0';

    with mode_reg select mode_out <=
        "00" when MODE_IDLE,
        "01" when MODE_CALIBRATE,
        "10" when MODE_RUN,
        "11" when MODE_FAULT;
end architecture rtl;

    port (
        clk       : in  std_logic;
        rst_n     : in  std_logic;

        osc_clk_b : in  std_logic;

    );
end entity phase_calibrator;

architecture rtl of phase_calibrator is
    signal sync_a, sync_b : std_logic_vector(1 downto 0) := "00";
    signal err_acc        : signed(7 downto 0) := (others => '0');
begin
    process(clk, rst_n)
    begin
        if rst_n = '0' then
            sync_a  <= "00";
            sync_b  <= "00";
            err_acc <= (others => '0');
        elsif rising_edge(clk) then
            sync_a <= sync_a(0) & osc_clk_a;
            sync_b <= sync_b(0) & osc_clk_b;

            if (sync_a(1) = '0' and sync_a(0) = '1') and not (sync_b(1) = '0' and sync_b(0) = '1') then
                if err_acc < 127 then
                    err_acc <= err_acc + 1;
                end if;
            elsif (sync_b(1) = '0' and sync_b(0) = '1') and not (sync_a(1) = '0' and sync_a(0) = '1') then
                if err_acc > -128 then
                    err_acc <= err_acc - 1;
                end if;
            end if;
        end if;
    end process;

    phase_err <= err_acc;

#!/usr/bin/awk -f
# pex_rc_check.awk — Zero-dependency RC delay & coupling budget checker
# Usage: awk -f pex_rc_check.awk ../../analog/parasitic_model.sp

function si(s,    low) {
    low = tolower(s)
    if (low ~ /f$/) { sub(/f$/, "e-15", low); return low + 0 }
    if (low ~ /p$/) { sub(/p$/, "e-12", low); return low + 0 }
    if (low ~ /n$/) { sub(/n$/, "e-9",  low); return low + 0 }
    return s + 0
}

BEGIN { max_tau = 5.0e-12 }

/^[Rr]/ { r_sum[subckt] += si($4) }
/^[Cc]/ { c_sum[subckt] += si($4) }
/^\.subckt/ { subckt = $2 }
/^\.ends/   {
    tau = r_sum[subckt] * c_sum[subckt]
    status = (tau <= max_tau) ? "PASS" : "WARN"
    printf "PEX %-20s R=%.2f Ohm  C=%.3e F  tau=%.3e s [%s]\n", subckt, r_sum[subckt], c_sum[subckt], tau, status
}
