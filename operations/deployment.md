There is no deployment target. This repository is source and evidence
only. Nothing in it is installed, served, or run as a service.

## What a release means here

A release means: a commit is pushed to AHMADALIPARR/sovereign-eda
only after scripts/release-gate.sh passes and the owner approves it.
The pushed commit, the gate log, and the watermark HEAD are the
release record.

## What a release does not mean

A release does not mean the code is flight-ready, safety-certified,
or ready for a NASA mission. It means the evidence in this tree
supports the requirements for this non-flight class, at the commit
recorded.
