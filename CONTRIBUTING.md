## Rules

- The owner writes the READMEs. Do not author long READMEs. Correct
  only paths that do not exist, and state the correction.
- Code the owner supplies as already verified is taken verbatim. Fixes
  are offered, never installed as default.
- V1 is untouched. New behavior goes in a new variant, benchmarked
  against v1.
- No stubs, skeletons, TODOs, or ellipses in code. No test result is
  claimed that was not produced by running the test.
- Every requirement has a traceability row. Every file is in the
  watermark. The release gate must pass before any push.
- License headers: every file that can carry one carries the SPDX
  header for LicenseRef-Sovereign-Leviathan-SL-AGPL3-001, Copyright
  (C) 2026 SnapKitty West. Ben Olmstead's malbolge.c is public-domain
  code and keeps his own header. No MIT license bearing the owner's
  name is ever added.
- The layout is the owner's. Do not move files to fit a template
  without his explicit direction.
